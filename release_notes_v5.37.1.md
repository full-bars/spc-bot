# Release Notes - v5.37.1

## 🪄 Persistent AI for Observed Soundings

This point release brings the persistent and proactive AI analysis features to the observed soundings channel.

### What's Changed
- **Sounding AI Buttons:** The "🪄 AI Analysis" button is now a permanent fixture on all sounding posts (RAOB and ACARS), including those generated by background monitoring tasks.
- **Instant Delivery:** Implemented proactive pre-fetching for sounding environments. The AI analysis is triggered immediately upon posting, so it's ready for you the moment you click it.
- **Restart-Proof:** Refactored button logic to use stateless IDs, ensuring all AI buttons continue to work even if the bot is updated or restarted.
